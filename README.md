# Meus Primeiros Dashboards - Power BI 📊

Olá! Este é o meu repositório onde estou guardando os meus primeiros projetos utilizando o **Power BI**. O objetivo deles foi aprender a conectar dados, criar visuais e entender as primeiras fórmulas.

---

## 📂 Projetos

### 1. Dash 1: Análise de Acessibilidade Educacional
Este foi o meu primeiro contato prático com a ferramenta.
* **O que fiz neste projeto:** Aprendi a fazer fundos dinâmicos, busquei entender como os gráficos funcionavam e criei gráficos de indicadores e filtros de região e ano. Também fiz um teste com um gráfico que mostrava as regiões, deixando destacadas as cidades mencionadas.

### 2. Dash 2: Gastos do Comitê
Neste segundo projeto, busquei evoluir um pouco mais as visualizações.
* **O que fiz neste projeto:** Busquei trazer mais padronização e utilizar melhor a ferramenta de "botões". Deixei cada tópico mais dividido, tornando o visual mais organizado e de melhor visualização. Procurei criar filtros de pesquisa que se encaixassem melhor na proposta, sempre enfatizando os valores para um bom controle e visualização dos gastos.

---

## 🛠️ O que utilizei
* **Power BI Desktop** para montar os gráficos e os relatórios.
* **Figma** para montar o design dos fundos (backgrounds).
* Dados vindos de planilhas do Excel **(com valores fictícios)**.
